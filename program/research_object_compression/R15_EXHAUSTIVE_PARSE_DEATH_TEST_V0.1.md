## 3. Token identity does not create a global symbol table

R15 supplies hostile cases directly.

### A / A_t

```text
PAGE_00: A   = adaptation capacity
PAGE_1:  A_t = action
PAGE_1:  A_t = alignment/correction capacity
PAGE_4:  A_t = available action space
PAGE_4:  A_t = alignment/correction capacity
```

The same token is reused with different meanings, including two meanings inside PAGE_1 and two meanings inside PAGE_4.

The parse makes each definition source-local and does not overwrite earlier meanings when a later definition appears.

\[
\boxed{
\text{token identity}
\neq
\text{formal identity}.
}
\]

```text
GLOBAL_SYMBOL_TABLE_FROM_TOKEN_IDENTITY     = CONTAINED
INTRA_ARTIFACT_SYMBOL_REUSE_AS_SAME_MEANING = CONTAINED
SYMBOL_MEANING_FROM_MOST_RECENT_DEFINITION  = CONTAINED
```


These are retained as local definitions rather than one polymorphic canonical C.

### R / E / Omega
