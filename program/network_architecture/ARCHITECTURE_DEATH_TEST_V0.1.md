## 1. Death-test standard

The candidate survives only to the extent that its structure can preserve all of the following separations:

\[
\boxed{
\begin{aligned}
\text{relation} &\neq \text{standing}\\
\text{message} &\neq \text{promotion}\\
\text{path} &\neq \text{composition}\\
\text{recurrence} &\neq \text{independence}\\
\text{provenance} &\neq \text{warrant}\\
\text{activation} &\neq \text{authority}\\
\text{contradiction} &\neq \text{global revocation}.
\end{aligned}
}
\]

A future kernel is not earned if the candidate schema itself collapses distinctions required to prevent self-generated authority.

\[

\]

A forward pass treats arrival of the `SUPPORTS` message as sufficient to promote `B` to `SUPPORTED` or `ESTABLISHED`.

### Candidate containment

The candidate explicitly freezes:

\[
\text{message arrival}
\neq
\text{claim activation}
\neq
\text{standing promotion}
\]

and assigns no authority to the network map itself.

### Verdict

```text
EDGE_AS_AUTHORITY_LAUNDERING = CONTAINED_AT_ARCHITECTURE_BOUNDARY
```

### Scope ceiling

This does not prove a future `Propagate` implementation will preserve the separation. It establishes only that the candidate does not constitutionally equate an edge with standing.

\[

\]

### Candidate containment

The candidate explicitly freezes:

\[
\text{relation recurrence}
\neq
\text{source independence}
\neq
\text{relation warrant}.
\]

No count-based confidence accumulator or global activation score is authorized.

### Verdict

```text
RECURRENCE_AS_WARRANT = CONTAINED_AT_ARCHITECTURE_BOUNDARY
```

## 5. Attack D — `BACKPROPAGATION_OVERREACH`

### Construction

A claim `C` has three distinct supporting warrant branches:

\[
E_1\rightarrow C,
\quad
E_2\rightarrow C,
\quad
E_3\rightarrow C.
\]

New evidence invalidates only `E_2`.

A generic graph backpropagation algorithm floods the connected component and emits:

```text
C = REVOKED
E1 = INVALID
E3 = INVALID
```

or otherwise destroys unaffected structure.

### Candidate behavior

The candidate says backward propagation must perform minimal revision and preserve `WHAT_DID_NOT_CHANGE`, but it does not yet define a dependency-sensitive revision operator or sufficient schema to compute whether `C` remains supported by `E1` and `E3`.

### Verdict

```text
BACKPROPAGATION_OVERREACH = NOT_YET_ADJUDICABLE_WITHOUT_REVISION_OPERATOR
```

### Boundary

This is not a surviving architecture failure because no backpropagation operator has been constituted. It is a hard gate on any future backward-pass kernel.

A future revision operator must prove that it can localize the affected warrant branch before any connected-component propagation is allowed.

## 7. Attack F — `SELF_REINFORCING_GRAPH`

### Construction

The candidate network contains:

\[
A\rightarrow B,
\quad
B\rightarrow C,
\quad
C\rightarrow A.
\]

Each relation has resolvable source/derivation provenance, but the cycle lacks an independently grounded standing-warrant root.

A naïve iterative propagation process repeatedly re-enters its own prior outputs and amplifies apparent support.

### Candidate defense

The candidate explicitly states:

\[
\text{recursive activation}
\neq
\text{new warrant}.
\]

However, the candidate node and edge records contain a generic field named `provenance` but no structurally separate representation of:

1. derivation/source provenance;
2. relation provenance;
3. standing-warrant provenance;
4. well-founded warrant-root status.

Therefore a future kernel using only the frozen candidate records could encounter a fully provenance-bearing cycle while lacking the represented distinction needed to decide whether the cycle possesses grounded warrant.

This repeats a known epistemic distinction at a new computational layer:

\[
\boxed{
\text{provenance}
\neq
\text{warrant}.
}
\]

### Verdict

```text
SELF_REINFORCING_GRAPH = HIT
```

### Shallowest localization

```text
ARCHITECTURE / WARRANT-PROVENANCE SEPARABILITY
```

### Minimal repair required before kernel

The network substrate must represent enough structure to distinguish **how a node/edge was derived** from **what grounds any standing transition it can license**.

The repair need not create a universal warrant ontology. It must only prevent a provenance-bearing cycle from impersonating a grounded warrant chain.

No implementation is authorized by this hit.

## 9. Attack H — `SCALAR_AUTHORITY_CEILING`

### Construction

The candidate edge schema contains:

```text
authority_ceiling
```

A future implementation assigns one scalar, ordinal level, Boolean, or generic magnitude to that field and computes downstream permission from it.

For example:

```text
AUTHORITY_CEILING = 0.8
```

or:

```text
AUTHORITY_CEILING = HIGH
```

would collapse scope-, purpose-, provenance-, jurisdiction-, and effect-specific authority into one dimension.

### Failure

The research program already preserves that authority is scoped and relational rather than a global scalar. The candidate field name does not itself represent the coordinates along which authority differs.

A generic single `authority_ceiling` slot can therefore become an interface that stores the word *authority* while operationally collapsing the distinctions necessary to constrain propagation.

### Verdict

```text
SCALAR_AUTHORITY_CEILING = HIT
```

### Shallowest localization

```text
ARCHITECTURE / AUTHORITY REPRESENTATION
```

### Minimal repair required before kernel

Replace the generic scalar-like ceiling assumption with a typed, scope-sensitive representation sufficient to answer the exact effect being adjudicated.

The death test does **not** establish the correct replacement schema.

It establishes only:

\[
\boxed{

\text{ is insufficiently specified for message-passing control}.
}

## 10. Attack I — `UNLICENSED_AUTHORITY_INTERSECTION`

### Construction

The proposed informal kernel shorthand is:

\[
\operatorname{OutputAuthority}
\le
\operatorname{InputAuthority}
\cap
\operatorname{EdgeAuthority}.
\]

This notation silently assumes that authority objects admit a common partial order and a meaningful intersection/meet operation.

### Failure

No such general authority algebra has been established.

Two authority-bearing objects may differ in provenance, jurisdiction, semantic purpose, effect type, activation condition, or other coordinates for which a single intersection operation is undefined or misleading.

Thus:

\[
\boxed{
\text{authority boundedness intuition}
\neq
\text{licensed authority lattice}.
}
\]

### Verdict

```text
UNLICENSED_AUTHORITY_INTERSECTION = HIT_AGAINST_PROPOSED_KERNEL_SHORTHAND
```

### Candidate impact

The frozen architecture candidate intentionally did **not** constitute the intersection formula as kernel semantics. Therefore the hit rejects the proposed shorthand rather than invalidating the entire candidate.

### Required boundary

Any future propagation rule must define authority effect locally for the relation and transition being evaluated rather than assuming a universal meet operation.

## 14. Shallowest sufficient revision

The death test does **not** justify implementing a network.

Before a `Propagate` kernel can be constituted, a successor architecture must minimally demonstrate how it preserves:

1. **warrant separability** — source/derivation/relation provenance cannot substitute for grounded standing warrant;
2. **effect separability** — a relation label cannot by itself authorize a downstream state transition;
3. **scope-sensitive authority** — authority cannot be compressed into one generic scalar ceiling;
4. **no assumed global authority meet** — boundedness must be defined locally for actual transition semantics;
5. **minimal-revision gating** — backward contradiction propagation remains unopened until dependencies and unaffected warrant branches can be localized.

No seven-layer architecture, message object, effect algebra, claim status system, propagation rule, or revision operator is earned merely by identifying these requirements.
